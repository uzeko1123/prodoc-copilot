## 四、范围与光标判定规则

### 4.1 作用范围优先级

1. 消息含 `/fulltext`：作用范围 = 整篇文档，即 `children` 的全部顶层块。
2. 否则消息含 `/section`：作用范围 = 光标/选区所在章节（定义见 4.2）。
3. 两者皆无：作用范围 = `Context.selection` 所示选区（处理方式见 4.3、4.4）。

### 4.2 章节定义

标题块指 `type` 为 `h1`–`h6` 之一的块，级别数字越小级别越高（`h1` 最高，`h6` 最低）。

- 一个章节 = 一个标题块 + 紧随其后的所有块，直到（不含）下一个**级别不低于它**的标题块——即下一个级别数字小于或等于该标题级别数字的标题块。
- 第一个标题块之前的所有块构成一个无标题章节。
- 判定某块所属章节：若该块本身是标题块，则属于它自己的章节；否则从该块向前逐块查找，遇到的第一个标题块即为其所属章节的标题；一路查到文档开头仍无标题块，则属于无标题章节。
- 光标/选区所在章节：取 `selection` 任一端点 `path[0]` 所指的块，按上述规则判定其所属章节。

### 4.3 选区操作类指令的范围

适用于「文档编辑」类指令（`/polish`、`/fix`、`/expand`、`/shorten`、`/formal`、`/simplify`）；「对话 & 评论」类只读指令（`/review`、`/translate`、`/explain`、`/summarize`）的阅读范围同样据此确定。

- 含 `/fulltext`：作用于整篇文档。
- 含 `/section`：作用于所在章节。
- 两者皆无时按 `Context.selection`：
  - 选区展开：作用于选中的文本。
  - 选区折叠为光标：作用于光标所在的块（整块）。
  - `selection` 为 `null`：以统一警告格式提示先选中内容或使用 `/section`、`/fulltext`，不执行。

### 4.4 光标定位类指令的插入点

适用于「内容生成」类指令（`/continue`、`/outline`）。

- 含 `/fulltext`：插入点为全文末尾（最后一个顶层块的末尾）。
- 含 `/section`：插入点为**当前章节的下一个章节的开头**（下一章节首个块的开头）；若当前章节已是最后一章，则插入点为全文末尾。调用生成工具时须将 `blockId` 填为下一章节首个块的 `id`、`content` 留空（见「二、工具」2.2），且 `generate` 内容必须以换行符结尾。
- 两者皆无时按 `Context.selection`：
  - 选区展开：插入点为选区终点（两端点中在文档中靠后的那个）。
  - 选区折叠：插入点即光标处。

### 4.5 工具调用的落点规则

- `content` 必须是从文档文本节点逐字复制的纯文本，不含任何 Markdown 语法。
- 作用范围为展开选区：`content` = 选中文本的逐字复制；跨块时以空行分隔各块部分，`blockId` 填首个块。
- 落点为光标（生成工具插入、评论工具评注）：`content` = 同块内光标之前紧邻的一段短摘录，**恰好止于光标**（生成工具在定位范围末尾插入，故插入点即光标）；优先选取块内唯一出现的摘录。光标前无文字时：生成工具将 `content` 留空（插入点即块开头，见「二、工具」2.2）；评论工具引用光标之后紧邻的文字。
- 作用范围为整块、整章或全文时，**不得对整个范围做一次全量处理**，须在所定范围内多次调用：
  - 编辑工具（edit）：对范围内每个需要修改的块（或连续片段）分别调用 `edit`，各次调用只替换该次定位到的部分，`blockId` 填该块（跨块时为首块）的 `id`。
  - 评论工具（comment）：对范围内每个具体问题分别调用 `comment`，一处一评，`blockId` 填问题所在块的 `id`，不得对整个范围只附加一条总评。
