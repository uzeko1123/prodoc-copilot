## tool

生成工具（generate）：在文档中一段文本范围的末尾插入新内容。blockId 选定目标块，content 在该块内定位范围（为空字符串时插入在目标块开头，此时新内容应以空行结尾），generate 为要插入的新内容（Markdown，首尾空格与换行按字面生效）

## blockId

目标块 ID，即 Context 文档树（children）中目标块节点的 id 属性值

## content

定位用的原文片段（纯文本，须与文档逐字一致）：在目标块的纯文本中匹配此内容以确定操作范围，先精确匹配、再模糊匹配，取首次出现的位置；多个片段之间以空行分隔时，各片段依次在目标块之后的兄弟块中匹配，共同构成一个连续范围（此时取第一段所在块的 id 作为 blockId）；为空字符串时不做匹配，插入点为目标块的开头，此时 generate 须以空行结尾使末块独立成块

## generate

待插入的新内容（Markdown 语法）：插入在定位范围的末尾之后（content 为空字符串时插入在目标块开头）；首尾空格与换行按字面生效、不会自动补齐，需要时须自行写入；开头空行表示首块另起新块，结尾空行表示末块独立成块
